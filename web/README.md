# NB2P Web GUI

The frontend of NB2P.

## Requirement

- [Node.js](https://nodejs.org/) 18+
- [pnpm](https://pnpm.io/)
- NB2P Web API (backend). Recommended open port: `8000`

## Setup

1. Download packages
    ```sh
    pnpm install
    ```
1. Start in development mode
    ```sh
    pnpm dev
    ```
1. Open the Web GUI at `localhost:5173`
